시안 3 — 크래프트Craft

아이 방의 공작 노트. 손으로 그린 선, 손글씨, 마스킹 테이프. 화면이 「앱」이 아니라 「도영이가 쓰는 물건」이 되게 한다.

서체
Nanum Pen Script 손글씨 표제 · Gaegu 400/700 본문. 인쇄체를 한 글자도 쓰지 않는다
타이포 스케일
42 → 27 → 19 → 15 → 12. 손글씨는 크게, 행간 1.68로 넓게 — 작으면 읽히지 않는다
격자·간격
격자를 일부러 깬다. 요소는 −2°~+2° 사이로 기울고 서로 조금씩 겹친다. 공책 줄(25px)이 유일한 기준선
면과 곡률
종이. 테두리는 feTurbulence로 흔든 선 — 자로 그은 직선이 없다. 반경 2~4
깊이
물건이 쌓인 깊이. 종이 그림자 + 테이프 + 폴라로이드 흰 테. 그림자는 부드럽고 방향이 제각각
내비게이션
노트 옆구리 색인 탭 — 오른쪽 가장자리, 엄지가 닿는 자리. 탭마다 다른 색지
색
크라프트지 #C9B393 + 색지 5장 + 형광펜 노랑
밀도
중간. 여백이 곧 종이라서 비어 있어도 비어 보이지 않는다
조작 표시
크레용 동그라미. 진행은 연필 점선과 종이비행기. 빌드 정보는 붙임쪽지로 아스팔트 띠에 붙는다

다른 넷과 갈라지는 지점: 직선과 격자를 버린다. 모든 선이 흔들리고 모든 요소가 기울어 있어, 화면이 만든 물건이 아니라 모은 물건처럼 읽힌다.
